# Pull Request Testing

## Purpose
This document describes the basic testing performed before raising a Pull Request.

## Testing Checklist

- [x] Verified the project structure.
- [x] Checked the Git branch.
- [x] Confirmed the working tree is clean before making changes.
- [ ] Verified the changes locally.
- [ ] Reviewed the Git diff.
- [ ] Confirmed there are no unwanted files.

## Expected Result
The changes should be committed to the feature branch and submitted through a Pull Request for review.

## Notes
This is a sample documentation change created to practise the GitHub Pull Request workflow.
